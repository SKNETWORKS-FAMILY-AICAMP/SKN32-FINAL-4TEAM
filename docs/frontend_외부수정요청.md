### B. 팀 공유 — "합성 데이터" 안내 배너 제거 (CLAUDE.md 데이터 원칙과 배치될 수 있음)
- **대상**: `frontend/js/planner-shell.js`의 `shell()` — 이전에는 `tfPlan.result.data_notice` / `tfPlan.report.data_notice`를 노란 배너(`.demo-note`)로 03/04/05(및 03-A) 화면 상단에 항상 보여줬다.
- **이유**: 사용자가 화면 4곳(03/04/05 등)에서 이 배너를 명시적으로 삭제해 달라고 요청해 반영했다. 다만 `frontend/CLAUDE.md` §데이터 원칙에는 "상품 가격·리뷰가 합성 카탈로그인 경우 서버가 주는 표시(`data_notice`)를 그대로 보여준다"는 규칙이 있어, 이번 변경이 그 규칙과 상충한다.

- **시급도**: 10월(장기) — 지금 당장 막는 이슈는 아니고, 문서·정책 정합성 확인용.
- **담당 영역**: 팀 전체(정책 결정) — 결정되면 프론트가 문서/코드 반영.

### C. 백엔드 팀 — 04(리스트 확정) 화면 "나의 장바구니"에 리뷰 정보 없음
- **대상**: 추천 결과 `items[].review` (및 `reason`/`checks`) 필드
- **이유**: 03(추천 결과)·05(리포트) 화면은 리뷰 데이터가 있으면 표시하도록 이미 프론트에 구현돼 있다(`tfReviewMetric`, `tfShowCartReviewSlide`). 다만 현재 시나리오 데이터에서는 모든 품목이 리뷰 정보 없이 내려와 화면에 "리뷰 정보 없음"만 보인다. 프론트 버그는 아니며, 리뷰 집계 파이프라인이 채워지면 자동으로 실제 수치가 보일 것으로 예상.
- **제안**: 리뷰 집계(`review_service` 등)가 데모/시나리오 데이터에도 값을 채우는지 확인 부탁.
- **시급도**: 10월(장기) — 데모 자체는 "리뷰 정보 없음" 상태로도 동작.
- **담당 영역**: 백엔드(리뷰 파이프라인)
